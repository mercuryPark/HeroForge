# HeroForge

JavaScript 기반 방치형 RPG 프로토타입입니다.

## Quick Start

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev`: 개발 서버
- `npm run build`: 프로덕션 빌드
- `npm run preview`: 빌드 결과 미리보기
- `npm run test`: 단위 테스트

## Implemented MVP Loop (Phase1)

- 자동 전투 루프(200ms 고정 tick)
- 경험치/레벨업
- 스테이지 진행
- 장비 드랍/강화
- 로컬 저장 + AFK 보상 계산

## Class Set

- Warrior

- Thief
