# HeroForge 밸런스 시트

## 목표
- 챕터 1~3 (스테이지 1~30): 무조작 자동사냥으로 클리어 가능
- 챕터 4부터: 장비 강화, 장비 교체, 스킬 운용 개입 필요
- 챕터 10: 최종 보스 챕터로 설계

## 운영 원칙
- 수치는 코드 하드코딩 대신 config에서 관리한다.
- 전투 수치 변경 시 `src/game/data/balance.js`만 수정한다.
- 장비 희귀도와 강화 확률은 `src/game/data/equipment.js`에서 관리한다.

## 전투 수치 공식
- 경험치: `(12 + stage * 2.05) * chapterRewardMultiplier`
- 골드: `(16 + stage * 3.1) * chapterRewardMultiplier`
- 적 HP: `(58 * (1 + (stage - 1) * 0.11) + stage * 6) * chapterEnemyHpMultiplier`
- 적 ATK: `7.2 * (1 + (stage - 1) * 0.11) * chapterEnemyAtkMultiplier`
- AFK 보상: 챕터 보상 배수와 스테이지 계수를 같이 반영

## 장비/강화 기준
- 강화 비용: `80 * 1.24 ^ 강화레벨`
- 강화 성공 확률/보너스: `src/game/data/equipment.js`
- 장비 드랍률: 챕터가 오를수록 소폭 감소
- 의도: 초반은 드랍으로 성장, 중반부터는 강화와 장비 선택이 중요

## 밸런스 점검 체크
- 20분 자동사냥 테스트에서 스테이지 30 전후 도달 여부
- 챕터 4 진입 시 장비 미강화 상태로 정체 발생 여부
- 챕터 5~6에서 강화 3~5단계 체감 여부
- AFK 8시간 수익이 온라인 플레이를 완전히 대체하지 않는지 확인
